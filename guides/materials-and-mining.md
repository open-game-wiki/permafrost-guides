## Confirmed scope

Scavenging and crafting are part of the official game description. The public overview does not provide an ore-location map, mining-tool hierarchy, or smelting conversion table.

## Resource-run checklist — editorial advice

Start from an actual recipe requirement. Check the exact material name and whether the game provides a location or tool hint. When you find a source, record the map location and the tool used; do not infer that all similar-looking objects yield the same material.

For processing, record both the input and actual output, together with any fuel consumed and the game build. Distinguish a single observed result from a guaranteed conversion or a random yield.

## Data currently withheld

Tool tiers, named ore routes, recipes, and conversion ratios still need current-build evidence. This page does not claim that any particular tool can mine a particular deposit.

A reliable location entry needs a map screenshot, a nearby recognizable landmark, the resource prompt, and a date/build. Availability or respawn behavior requires repeated checks and should be recorded separately.
