## Confirmed multiplayer support

Steam lists online co-op for up to four players in total: you and up to three friends. The official Early Access description says cooperative multiplayer is implemented. Solo play is also supported.

## Before arranging a session — editorial checklist

- Confirm that everyone has installed the same current update.
- Follow the host/join options shown in the installed build; this site has not verified the precise menu labels.
- Agree on the session owner and check where each player's progress is saved before a long expedition.
- If joining fails, record the exact error, whether everyone is affected, and the game build. Retry after updating and restarting the game/client before making wider system changes.

We have not verified dedicated-server availability, password controls, save ownership, cross-play, host migration, or progress sharing. Do not plan unattended or persistent sessions on the assumption that these features exist.

## Security errors and support reports

A connection timeout alone does not establish that Windows security software blocked the game. Microsoft's Smart App Control does not offer a per-application exception. The previous instruction to add the game to a Smart App Control exclusion list was incorrect and has been removed.

If Windows explicitly blocks a file, preserve the exact message and contact the developer through the game's official support/community links. Do not disable a security feature solely on this guide's account.
