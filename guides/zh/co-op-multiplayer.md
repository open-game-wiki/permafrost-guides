《Permafrost》正式支持最多 **4 人在线合作联机**（你与最多三位好友组队）。尽管独自在极寒废土中求生别具末世氛围，但多人组队能够大幅提升生存效率：一人负责据点防寒建设，一人专注打猎制皮，两人深入矿坑开采铁矿。

本文将详解联机房间建立步骤、4 人小队黄金分工以及常见联机卡顿与连接超时排查方案。

---

## 一、 如何创建与加入多人联机房间

在抢先体验版阶段，游戏采用玩家本地主机（P2P / 局域网穿透）托管模式，世界存档保存在房主电脑中：

### 房主创建房间流程：
1. 在主菜单点击 **多人游戏（Multiplayer）**；
2. 选择 **创建主机（Host Game）** -> 选择已有存档或新建世界；
3. 房间安全设置：
   * **房间名称（Server Name）：** 自定义专属名称；
   * **最大人数：** 默认为 4 人；
   * **隐私模式：** 强烈建议勾选 **仅限好友（Friends Only）** 或设置 **密码（Password）**，防止野队路人进房恶意拆家；
4. 点击 **启动会话（Start Session）** 进入世界后，按下 `Shift + Tab` 呼出 Steam 覆盖好友列表，右键点击好友直接发送游戏邀请。

### 好友加入流程：
* **通过 Steam 邀请：** 在聊天框点击“加入游戏”即可自动拉起客户端直连；
* **通过游戏内大厅：** 点击“查找游戏（Find Game）”，在房间列表中筛选房主房间名并输入密码。

## 二、 4 人小队黄金职业分工矩阵

多人模式下物资消耗（食物、饮用水、室内保暖炉消耗）按人数成倍上升，盲目乱跑极易集体冻饿而亡。建议实行明确分工：

| 小队核心战术角色 | 推荐职业搭配 | 核心日常职责与战术分工 |
| :--- | :--- | :--- |
| **据点总工程师** | 幸存者 + 工程师 | 负责伐木扩建、室内屋顶严密咬合、保证壁炉营火长明不灭 |
| **野战猎人** | 幸存者 + 追踪者 | 负责制作弓箭打猎、制皮架熟皮、烤熟食物与驯服小狗 |
| **地下矿工** | 走私者 + 工程师 | 携带燧石镐与铜镐，负责深入洞穴挖掘铜矿、煤矿与铁矿 |
| **尖兵特工** | 走私者 + 拾荒者 | 负责搜刮太阳能农场废墟、寻找军用枪械图纸、撬锁搜集电线废料 |

## 三、 常见联机故障排查与修复技巧

### 1. 连接超时（Connection Timed Out / Failed to Join）
* **排查 1：Steam 客户端版本：** 确保房主与加入者均已升级至 Steam 最新补丁版本（版本号不一致会导致握手失败）；
* **排查 2：防火墙放行：** 在 Windows 安全中心中，确保 `Permafrost.exe` 允许“专用网络”和“公用网络”双向通信；
* **排查 3：Windows 智能应用控制冲突：** 部分玩家反馈 Windows Smart App Control 会误判阻止 P2P 握手，将其添加排除项即可恢复秒连。

### 2. 存档回档与不同步问题（Desync Prevention）
* **房主下线原则：** 房主在退出游戏返回主菜单前，务必提醒所有队友在各自床铺上完成一次“睡眠存档”。避免非正常强退导致客户端背包数据丢失。
